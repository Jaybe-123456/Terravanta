# Terravanta platform overview

## Creative contract

**Goal:** Explain how Terravanta connects farmer records, veterinary follow-up, a consented WhatsApp text channel, cooperative payout-close work and processor claim evidence, while keeping AI optional and people accountable.

**Output:** HyperFrames · 1920 × 1080 · 30 fps · 52 seconds · 1,560 frames · instrumental soundtrack only; no founder narration is included.

**Look:** Authored product screens, not generic farm imagery. Background `#F2F5F1`; ink `#19382A`; paper `#FFFFFF`; forest `#315F3C`; amber `#B98225`; dividers `#D9E1D8`; system sans. Main title 63–68 px, body 24–27 px, UI labels 16–25 px. 112 px side margins. The opening connection map identifies technology roles with official Render and Supabase wordmarks and the FastAPI project mark; Vercel appears as plain text. It is a technology reference, not a partner/customer logo wall. NVIDIA is named as an optional server provider; WhatsApp Business Platform is shown as a consent-based text workflow. No metrics, testimonials, customer logos or invented outcomes.

**Truth in product:** The current deployment uses a Vercel web UI, Supabase Auth, FastAPI on Render and PostgreSQL/PostGIS. Provider logos identify technology roles only and do not imply endorsement. Farmer-entered records keep source attribution; veterinarian workflows include follow-up dates and outcome capture. WhatsApp is an illustrative paired, consented text path for veterinary requests; production delivery requires an approved Meta business profile, verified phone and enabled webhook. It does not accept documents or images. A Terravanta web account, active consent and one-time number pairing are needed; a separate native Terravanta mobile app download is not. A signed webhook accepts messages from a linked participant, the API associates text with the request code, and an outbox/worker routes opted-in replies and delivery status. Cooperative closes and processor claims use manual source uploads/imports; no processor MIS connector or payment rail is represented. Terras routing is deterministic. NVIDIA farm/veterinary drafts require server configuration plus explicit per-request consent; all outputs remain human-reviewed drafts.

**Examples:** Every screen is visibly marked `ILLUSTRATIVE PRODUCT FLOW`; fields and messages are synthetic. The film claims no real customer success, clinical outcome, productivity change, debt determination, recovery or ROI.
